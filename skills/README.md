# skills

Team skills for the agents: one folder per skill, each with a SKILL.md. This folder is searched first (see SKILLS_PATH) and is copied into the Docker image.

Vendored sets, each with a SOURCE.md (where it came from, the commit, how to update):
- `mattpocock/`: Matt Pocock's skills (MIT).
- `ponytail/`: Dietrich Gebert's ponytail (MIT): the smallest complete change. The coder and the fixer name it `ponytail`.
- `superpowers/`: Jesse Vincent's Superpowers (MIT): test-driven development, verification before completion, systematic debugging, writing plans, receiving code review.
